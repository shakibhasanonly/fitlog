# 💪 FitLog

A responsive workout library built with **Next.js** and **Tailwind CSS**. Users can browse workouts, view details, create today's workout plan, save workouts, and manage their fitness routine.

# Live Site

**Live:** YOUR_VERCEL_LINK

# Technologies

* Next.js
* React
* TypeScript
* Tailwind CSS
* React Icons
* React Hot Toast

# Features

* Browse workouts from the API
* View workout details
* Add to Today's Plan
* Save workouts for later
* Sort workouts by Duration, Calories, and Rating

# Installation

```bash
git clone https://github.com/shakibhasanonly/fitlog.git
cd fitlog
npm install
npm run dev
```
