# FitLog

A responsive workout library built with Next.js and Tailwind CSS.

## Live Site

https://fitlog-sigma-gules.vercel.app/


## GitHub Repository

https://github.com/shakibhasanonly/fitlog

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Icons
- React Hot Toast

## Features

- Browse workouts from the API
- View workout details
- Add workouts to Today's Plan
- Save workouts for later
- Sort workouts by Duration, Calories, and Rating
